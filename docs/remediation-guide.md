# Remediation exercises

Use these exercises after learners observe the GitHub Advanced Security findings.

1. Replace string-built SQL in `searchExpensesUnsafe` with parameterized queries.
2. Validate receipt filenames and resolve paths inside the configured uploads directory.
3. Replace shell command construction with `child_process.execFile` and fixed arguments.
4. Render untrusted notes through EJS escaping or a trusted sanitizer.
5. Block `__proto__`, `constructor`, and `prototype` keys before merging preferences.
6. Normalize log messages before writing them.
7. Add rate limiting to the demo login route.
8. Upgrade vulnerable packages and review the package lockfile changes.
9. Replace the secret placeholders only with approved inactive training keys.
10. Refactor the code quality lab examples to remove duplicate logic and unreachable code.
